02 / Data plane

协议流，清晰而克制

Push 面向外部调用；Pull 面向队列驱动。两者都把任务统一映射为 TaskContext。

01 — Push ingress

平台主动调用你的公开 HTTPS endpoint

  1. 接收原始 body，读取签名、run ID 与 X-IR-Idempotency-Key。
  2. 以 HMAC-SHA256 校验 body；缺失、畸形或不匹配直接返回 401。
  3. 解析任务并进入共享执行链路；内部异常仅记录日志，响应不泄露内部细节。
  4. 返回 V2 信封：payload_result、payload_info、contract_version 与 usage。

02 — Pull egress

worker 从平台队列长期认领工作

  1. claim 长轮询；204 无任务时立即再次认领。
  2. 以受监督的串行方式处理任务，同时按配置 renew 租约。
  3. 409 BOUND_CLAIM_CONFLICT 或任务超时：立刻放弃，不再 complete。
  4. 成功或脱敏失败状态通过 complete 回传；独立循环持续 heartbeat。

03 / Guardrails

安全设计不是附加项

服务把可伪造、可失控和可泄露的常见失败模式前置到配置校验与明确的协议边界。

⌘

原始 MAC 校验

服务对原始请求体计算 HMAC-SHA256，并使用 Go subtle.ConstantTimeCompare 做常数时间比较。

⊘

启动期拒绝

Push 密钥为空或仍是 change-me 时拒绝启动；零 heartbeat / renew / task 周期也会在运行前被拦截。

◌

错误脱敏

Push 不向调用方回显执行器异常；Pull 回传稳定、可机读的错误码，完整错误仅留在受控日志。

04 / Control surface

配置矩阵

加载优先级：config/default.toml → config/{env}.toml → IR__* 环境变量。

环境变量默认值运行语义
IR__SIGNING_SECRET—Push HMAC 密钥；必须替换占位值。
IR__SIGNATURE_ENCODINGhexhex 或 base64，大小写不敏感。
IR__PULL_ENABLEDfalse开启 claim / complete / renew / heartbeat worker。
IR__QUEUE_URL—必须使用绝对 HTTPS；仅回环开发地址允许 HTTP。
IR__CLAIM_TIMEOUT_SECS60长轮询读超时；必须 ≥ 35 秒。
IR__RENEW_INTERVAL_SECS30任务租约续期；必须大于 0。
IR__TASK_TIMEOUT_SECS600单任务最大执行窗口；到期即放弃。
DEPLOYMENT NOTE将密钥与 bind token 注入部署环境，绝不写入仓库。对外的 Push endpoint 必须使用可访问的 HTTPS；Pull worker 可以部署在私有网络。
