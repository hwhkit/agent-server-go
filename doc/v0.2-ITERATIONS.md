# v0.2 迭代计划：千级 Agent 运维视角优化

> 视角：AI Agent 管理员，通过本平台管理数百~上千个智能体。
> 机制：30 轮迭代上限，每轮 3 项；每轮全量门禁绿后提交推送；
> 「迭代完成」由自审计判定——backlog 全部关闭或剩余项明确标记为「不做/延后」。
> 原则：线协议冻结（/ir/push、/agent-api/v1、/agent/{slug}、A2A 不变）；
> DB 只增不改；整洁架构分层不放松（archguard 守护）。
